ELENE'S LITTLE CORNER 💗
========================

WHAT'S INCLUDED
- index.html: the website
- style.css: scrapbook styling and responsive layout
- script.js: interactive encouragement, virtual hug, IELTS corner, feelings check-in, secret letter reveal, and photo lightbox
- photos/: all 18 personal photos, included and ready to display
- stickers/: the supplied sticker/meme images, displayed in the meme wall

HOW TO OPEN IT
1. Extract the ZIP file.
2. Open the elene_motivational_website folder.
3. Double-click index.html. The website works locally; an internet connection is only needed for optional Google Fonts.

HOW TO PUBLISH IT
- Netlify: upload the extracted project folder using the site's deploy flow.
- GitHub Pages: upload the contents of this folder to a repository, then enable Pages in repository settings. Keep the photos and stickers folders in place so their paths remain valid.
